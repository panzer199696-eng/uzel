# Эталон для замера WER

## Зачем

Без эталона фраза «русский язык распознаётся лучше, чем у Omi» — пустая.
WER (word error rate) считается один раз на базовой сборке и потом при каждой
смене модели или настроек. Порог приёмки — **WER ≤ 15 %** (критерий A1 проекта).

## Как получить эталон

Записать **30 минут реальной речи в реальных условиях** — не диктофонный тест
за столом, а то, как устройство будет использоваться:

1. Кулон на груди / в нагрудном кармане, как при носке.
2. Смесь ситуаций: разговор один на один, разговор в шуме (улица, машина, стройка),
   монолог-наговор, телефонный разговор рядом.
3. Обязательно — рабочая лексика: АОСР, КС-2, М-29, ГОСТ, шифры, фамилии,
   числа и даты. Именно на них универсальные модели ошибаются, и именно здесь
   наше преимущество над Omi должно быть видно.
4. Сохранить исходник WAV/Opus сюда: `tests/wer/эталон-01.wav`.

Транскрипт вручную (`эталон-01.txt`) — можно сделать в два прохода: черновик любой
моделью, затем вычитка. Вычитка обязательна, иначе меряем модель по самой себе.

## Формат

```
tests/wer/
  эталон-01.wav          исходное аудио 16 кГц моно
  эталон-01.txt          выверенный вручную транскрипт (истина)
  замеры/
    ГГГГ-ММ-ДД-<бэкенд>.md   результат прогона: WER, время, настройки
```

## Как запустить замер

Проще всего — команда приёмки (P13, 25.09.2026): проверит окружение, скажет,
чего не хватает, и сама посчитает WER с вердиктом по A1:

```powershell
uzel.cmd homecoming            # то же: uzel.cmd приёмка-возвращения
```

Замер напрямую, без проверок окружения:

```powershell
uzel.cmd wer tests\wer\эталон-01.wav tests\wer\эталон-01.txt
```

- `--backend local|groq` — какой бэкенд мерить (по умолчанию порядок из настроек)
- `--threshold 0.15` — порог приёмки
- `--no-vad` — без отсечения тишины, чтобы сравнить

Отчёт ложится в `tests/wer/замеры/ГГГГ-ММ-ДД-<бэкенд>.md`, рядом — что именно
распозналось. Код возврата 0, если порог пройден, 1 — если нет.

## Правила подсчёта

- Нормализация перед сравнением: нижний регистр, снятие пунктуации, «ё» → «е»,
  числа прописью → цифры.
- Считается по словам: `WER = (S + D + I) / N`, выравнивание по Левенштейну.
- Отдельно фиксируется **WER по доменным терминам** — на нём и меряется польза
  словаря из FR-023. Общая цифра его размазывает: в реальном примере 24.08
  общий WER был 13 % (порог формально пройден), а термин «освидетельствования»
  при этом потерян целиком.

⚠️ Две вещи, на которых измеритель ошибался и был починен:

1. **Подряд идущие числительные складывались.** «один два три» превращалось в
   «6». Теперь разряды обязаны убывать: «сто двадцать три» — число, а
   перечисление остаётся перечислением.
2. **Доменные слова не опознавались из-за окончаний.** Список хранил
   «освидетельствование», а в речи звучит «освидетельствования» — проверка по
   началу слова промахивалась ровно на том термине, ради которого словарь и
   нужен. Теперь список хранит основы.
