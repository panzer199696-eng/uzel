# История версий Android-моста УЗЕЛ

## Не выпущено (ветка i18n)
- Два языка: английский (`values/`, умолчание Android) и русский (`values-ru/`); язык — по
  системе, на Android 13+ можно выбрать язык только для УЗЛА (Настройки → «Язык»).
  Все строки экрана, уведомлений и плиток — в ресурсах; паритет переводов проверяет
  `StringsParityTest` в `:core:test`.
- Пишется ли запись — по машинному коду ответа ядра (`код`), а не по слову «выключена»:
  ядро с английским интерфейсом отвечает `off`, и старый разбор считал бы, что запись идёт.
- Причина отказа ядра — кодом (`FailReason`), текст — из ресурсов на языке телефона.

## 0.3.1 — 26.10.2026
- Обновление прошивки по воздуху без запроса MTU: загрузчик Adafruit на кусках по 244 байта
  обрывал приём (OPERATION_FAILED), по 20 байт — работает (так же шлёт мост с ПК).
- Если кулон не виден в эфире 10 с, мост подключается к нему напрямую по запомненному адресу:
  Android держит связь с сопряжённым кулоном и после остановки моста, и кулон перестаёт рекламироваться.

## 0.3.0 — 26.10.2026
- Совместимость с прошивкой УЗЛА 0.1.0: кулон отдаёт звук только сопряжённому телефону.
  Если Android сам не предложил сопряжение — мост сопрягается явно; кулон принимает новое
  устройство, только пока лежит на зарядке (USB).
- Поиск кулона и по имени `UZEL`.
- Обновление прошивки по воздуху: Настройки → «Прошивка кулона» → файл
  `uzel-fw-<версия>-dfu.zip` (библиотека Nordic DFU 2.11.0, Legacy DFU через загрузчик
  Adafruit). Мост на время заливки отключается и включается сам.
- Мост запоминает MAC кулона (нужен обновлению).

## 0.2.0 — 23.10.2026
- Экран на Compose + Material 3 Expressive, Material You, адаптив под раскрытый Find N5.
- Разделы: Кулон, День, Заметки (с метками момента), Поиск; карточка разговора с расшифровкой.
- Приватность ядра с телефона: тишина 10 мин / 1 час, приват, снять.
- Плитки быстрых настроек «УЗЕЛ» и «Метка», ярлык «Метка момента».
- Живучесть на ColorOS: нет карточки в «Недавних» — смахивание не убивает мост; сторож раз в 5 мин;
  автозапуск после перезагрузки и обновления.
- Уведомление службы — минимальной важности, в шторке не видно.
- Android 17: разрешение `ACCESS_LOCAL_NETWORK`, без него ядро в домашней сети недоступно.
- Тулчейн: AGP 9.4.1, Gradle 9.8.2, SDK 37.

## 0.1.0 — 20.09.2026
- Первый мост кулон → ядро: BLE, служба переднего плана, спул, экран на голых View.
