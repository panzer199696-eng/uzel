# Разбор Omi: что берём, что чиним

Основано на фактах, добытых при сборке и эксплуатации кулона в августе 2026
(подробности — в рабочих заметках автора), а не на маркетинге.

## Что у Omi сделано хорошо — берём

| Решение | Почему берём |
|---|---|
| Открытый протокол BLE, MIT | сервис `19b10000-e8f2-537e-4f6c-d104768a1214`, аудио `…0001`, кодек `…0002`; даёт совместимость в обе стороны |
| Opus 16 кГц | правильный компромисс: речь разборчива, поток мал |
| Zephyr / nRF Connect SDK | нормальная база для прошивки, есть форк-точка |
| Модель «разговоры + факты + задачи» | верная декомпозиция памяти, повторяем |
| MCP-сервер как способ отдать память агентам | правильная идея, делаем свою, локальную |
| SDK на 5 языках | планка по разработческому опыту |

## Что сломано или не сделано — чиним

| Проблема Omi | Факт | Наше решение |
|---|---|---|
| Аудио уезжает в облако США | подтверждено; для коммерческой тайны непригодно | локальная обработка, облако — явный опт-ин |
| Подписка $19/мес, 1200 мин бесплатно | ~20 ч/мес — на постоянную носку не хватает | self-host, 0 ₽ |
| Шлёт эфир постоянно | замерено 4,6 КБ/с, 1123 пакета за 10 с | gate + Opus DTX на устройстве |
| Ушёл телефон — аудио потеряно | буфера на устройстве нет | кольцевой буфер в QSPI 2 МБ |
| OTA ломает устройство | два падения 21.08.2026; условие `no_usb` спрятано в ответе бэкенда | MCUboot, две банки, откат |
| Спикеры не размечены | `get_people` пусто при 32 фактах и 7 разговорах | pyannote + enrollment голосов |
| Русский язык не заявлен | качество на живой речи неизвестно | GigaAM-v2 + доменный словарь, WER меряем |
| Сервер не переключить настройкой | `OMI_API_BASE_URL` зашит через envied при сборке | своё приложение, свой сервер по умолчанию |
| Нет управления с устройства | всё через приложение | тапы по корпусу через IMU |
| Нет индикации записи | собеседник не знает, что его пишут | LED + жест мьюта |
| Self-host бэкенда нереален | Firebase + Firestore + Pinecone + Redis + Deepgram + OpenAI + ngrok | SQLite + Qdrant + FastAPI, `docker compose up` |

## Чего у Omi нет вообще — наши козыри

1. **Работа с чужим железом как продукт.** Наш мост подключается к уже купленным
   кулонам Omi/Friend. Оффер «оставь кулон, выкинь подписку» не требует производства.
2. **Режим коммерческой тайны.** Расписание и геозоны, где запись физически выключена,
   плюс режим «только мой голос». Для стройки, закупок и юристов — условие входа.
3. **Память как граф сущностей**, а не лента разговоров: люди, проекты, обязательства,
   даты и связи между ними.
4. **Доменная лексика.** Свой словарь (АОСР, КС-2, ГОСТ, имена проектов) — там, где
   универсальные модели стабильно ошибаются.
5. **Экспорт в Obsidian нативно**, без стороннего плагина, который ставится вручную.

## Что из опыта Omi стоит помнить при своей разработке

- Прошивка Omi ждёт бутлоадер **0.9.0**; на заводском Seeed 0.6.1 OTA не проходит.
- На прошивке Omi (Zephyr) 1200-бод touch не работает — нужен физический двойной RST,
  а в корпусе Triangle v1 отверстия под кнопку нет. **В своём корпусе отверстие сделать.**
- Плата на USB опознаётся по-разному в трёх режимах (`2886/8045` завод, `2886/0045`
  бутлоадер, `2FE3/0100` прошивка Omi на Zephyr); неизменный признак — серийник в `PNPDeviceID`.
- Заряд идёт только при включённом выключателе; защиты от переразряда нет — батарея с PCM обязательна.
