## Ключевые решения и почему

### 1. Шина событий в центре
Всё, что делает система, — событие. Коннекторы подписываются, а не вызываются
из ядра. Отсюда «простая интеграция»: новый канал = новый подписчик, ядро не
трогаем. Это же даёт вебхуки бесплатно.

### 2. Совместимость с протоколом Omi — сознательная
Сервис `19b10000-e8f2-537e-4f6c-d104768a1214`, аудио `…0001`, кодек `…0002`.
Свой кулон рекламирует и его, и расширенный сервис. Даёт:
- наш мост работает с чужими кулонами Omi/Friend → рынок с первого дня;
- наш кулон работает с приложением Omi → пользователю есть куда отступить.

### 3. Экономия эфира — на устройстве, а не на мосту
Замерено на штатной прошивке Omi: **4,6 КБ/с непрерывно** (36,8 кбит/с),
это 248 МБ за 15 часов, радио включено постоянно.
Что делаем:
- **Opus DTX** — в тишине кодек шлёт «комфортный шум» примерно раз в 400 мс
  вместо пакета каждые 10–20 мс. Почти бесплатная фича, у Omi не включена.
- **Gate до энкодера** — в тишине энкодер вообще не запускается (экономия CPU,
  а не только радио).
- **Pre-roll 300 мс** в кольцевом RAM-буфере, чтобы не срезать начало фразы,
  и hangover 800 мс, чтобы не рвать речь на паузах.
- **Wear-detect по IMU**: неподвижен >2 мин → микрофон и радио в глубокий сон.

При типичной доле речи 20–30 % в сутки средний поток падает примерно до
1,0–1,5 КБ/с. Точная экономия — только замером на кулоне с амперметром (Э3; замеров пока нет).

### 4. Буфер во flash
На XIAO nRF52840 Sense есть 2 МБ QSPI (P25Q16H). При 16 кбит/с и активном gate
это ≈17 минут чистой речи, то есть больше часа реального времени.
Кольцевой лог + докачка при восстановлении связи. У Omi при уходе телефона
аудио теряется безвозвратно.

### 5. Жесты через IMU — ноль лишних деталей
LSM6DS3TR-C уже на плате и уже опрашивается ради wear-detect:
- **2 тапа** — «запомни это»: метка в поток, сегмент уходит в саммари с приоритетом;
- **3 тапа** — «приватно»: жёсткий мьют на 10 минут, LED красный, аудио не пишется;
- **переворот и удержание** — стоп-запись до следующего жеста.
В корпусе Triangle v1 нет отверстия под RST, физическую кнопку добавлять нечем —
тапы решают задачу без переделки корпуса.

### 6. Русский язык как первый класс
- **GigaAM-v2** (Сбер, открытая, лучший WER по русскому) — основной путь для ru.
- **faster-whisper large-v3** на GTX 1660 Ti (int8) — универсальный фолбэк.
- **Groq whisper-large-v3** — быстрый облачный путь, когда нужен результат сейчас
  (проверено 19.08.2026: русский распознаёт, ключ живой).
- Роутер выбирает по языку, длине сегмента и загрузке GPU.
- Постпроцессор с доменным словарём (АОСР, КС-2, ГОСТ, имена людей и проектов) —
  именно на этом Whisper сыпется, и именно это Omi не чинит.

### 7. Приватность как архитектурное свойство
- Аудио по умолчанию не покидает локальную сеть; облачный STT — явный опт-ин
  с флагом на уровне сегмента.
- Стоп-режимы: жест, расписание («рабочие переговоры 10:00–12:00 не писать»),
  ключевая фраза, геозона.
- Сырое аудио удаляется после расшифровки по настраиваемому TTL (по умолчанию 7 дней).
  Исполняет его сам ночной батч последним тактом (с P11.2, 25.09.2026; до того —
  только ручная `uzel purge`). Звук ещё не расшифрованных реплик TTL не трогает.
  Порядок объёма: **8,7 МБ за 20 минут при доле речи 0,25** (прогон 23.09) —
  около **600 МБ в сутки**, то есть при TTL 7 суток в `uzel-data\audio` и
  `queue\done` постоянно лежит **~4 ГБ**.
- Видимая индикация записи — не опция, а часть спецификации железа.

### 8. Хранилище
- **SQLite** — сегменты, разговоры, люди, факты, задачи, метки. Одна файловая БД,
  бэкап копированием, никакого Firestore.
- **Qdrant** — векторный поиск во встроенном режиме: файлы в каталоге данных, отдельный сервер не нужен.
- **Obsidian** — экспорт человекочитаемой копии в markdown. Нативно, без плагина.

## Стек

| Слой | Технологии | Почему |
|---|---|---|
| Прошивка | Zephyr / nRF Connect SDK, форк firmware Omi (MIT) | уже работает на этом железе, лицензия позволяет |
| Мост desktop | Python + bleak | кроссплатформенный BLE без нативной сборки |
| Мост Android | Kotlin, Compose, системный BLE | без лишних зависимостей; логика в чистом Kotlin под unit-тестами |
| Ядро | Python 3.12, FastAPI, SQLite, Qdrant | всё локально, одна файловая БД |
| STT | GigaAM-v2, faster-whisper, Groq | ru-первый + бесплатный фолбэк |
| VAD | Silero (сервер) + свой gate (устройство) | двухступенчато: дёшево на МК, точно на сервере |
| Диаризация | pyannote 3.1 | локально, на GPU |
| LLM | Ollama на этом ПК (qwen3 / qwen2.5); облачные бэкенды — только явно | разбор не покидает ПК |
| Упаковка | Docker Compose + Windows-инсталлятор | «один шаг» из концепции |
