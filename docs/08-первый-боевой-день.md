# Первый боевой день — чек-лист

> Составлено 25.09.2026 (пакет P13) как чек-лист первого дня с кулоном.
> Порядок: вечер возвращения — замер WER (гейт A1), следующий день — носка (A2).
> Всё, что ниже про BLE, к моменту составления проверялось **только эмулятором** протокола.

## Вечер возвращения — гейт A1 (около часа)

```powershell
uzel.cmd homecoming
```

(то же самое — `uzel.cmd приёмка-возвращения`; ASCII-имя надёжнее в `cmd.exe`).

Команда проверит окружение (модель VAD, whisper, Ollama, место на диске, живость
ядра) и скажет, чего не хватает. Дальше по её подсказкам:

1. Записать 3 минуты по `tests/wer/текст-для-начитки.md` — кулон на груди,
   обычным темпом, третья часть — свободная речь.
2. Положить `tests/wer/эталон-01.wav` (16 кГц моно; если запись в другом
   формате — команда подскажет строку `ffmpeg`).
3. Вычитать расшифровку **дословно** руками в `tests/wer/эталон-01.txt`.
4. Запустить `uzel.cmd homecoming` ещё раз — посчитает общий WER, WER по
   терминам, скорость (RTF) и напечатает вердикт по A1. Отчёт — в
   `tests/wer/замеры/ГГГГ-ММ-ДД-приёмка-<бэкенд>.md`.

Коды возврата: 0 — A1 пройден, 1 — не пройден, 2 — нет эталона,
3 — окружение не даёт посчитать.

## Утро: включить

1. **Кулон** зарядить и **отвязать от телефона**: при активном соединении
   BLE-реклама прекращается, и с ПК кулон не виден вообще.
2. **Ядро с окном:** `uzel.cmd app` (если стоит автозапуск —
   `uzel.cmd autostart status`, окно уже поднято). В окне `/ui` — статус,
   очередь, кнопки «Пауза 30 минут» и «Приват».
3. **Мост:**
   ```powershell
   .venv\Scripts\uzel-bridge.exe --scan
   .venv\Scripts\uzel-bridge.exe --address <MAC> --uid pendant-1 --spool-dir $env:USERPROFILE\uzel-data\bridge-spool
   ```
   `--spool-dir` указывать явно: умолчание `data/bridge-spool` относительное и
   при запуске из папки проекта кладёт сырой звук на Рабочий стол, в зону
   бэкапа Google Drive (находка 8 аудита, пакет P11.2).
4. **Дешёвый проход конвейера** — отдельным окном, на весь день:
   ```powershell
   uzel.cmd worker ingest --loop
   ```
   ⚠️ Ни ядро, ни окно сами конвейер **не запускают** — без этой команды звук
   копится в очереди и никуда не идёт.

## Днём: проверить, что пишется

- Мост раз в 30 с печатает счётчики: пакеты растут, потерь нет.
- В окне `/ui` растёт очередь и появляются реплики (пока без текста —
  расшифровка ночью).
- Разговор, который не должен попасть в память, — кнопка «Приват» или
  `uzel.cmd privacy mute 30`.

## Вечером: разобрать день

```powershell
uzel.cmd llm-check            # Ollama жива, облака в штатном пути нет
uzel.cmd worker batch         # расшифровка -> разговоры -> разбор -> заметка
```

Батч идёт в два такта (whisper, выгрузка, потом Ollama — вместе в 6 ГБ не
влезают); на замере 19.09 (P5) полный цикл на 4 с звука занял 160 с, из них
83 с — холодный старт Ollama; на целый день закладывать час и больше. Оборвался — `uzel.cmd worker recover`
и повторить `batch`.

## Где смотреть результат

- **Заметка дня:** `<хранилище Obsidian>\Проекты\Узел\Дни\ГГГГ-ММ-ДД — день.md` —
  факты с таймкодами, без дословных реплик.
- **Задачи:** `<хранилище Obsidian>\Проекты\Узел\Входящее — задачи.md`.
- **Разговор целиком:** `uzel.cmd search <слово>`, затем `uzel.cmd show <id>`.
- **Что отсеял бы фильтр качества:** `uzel.cmd quality-report --day ГГГГ-ММ-ДД`.

## Что записать себе по итогам дня

- Имеет ли заметка дня смысл — это и есть A2, проверка не кода, а пользы.
- Сколько звука ушло в `uzel-data` (ожидание — порядка 600 МБ в сутки; по TTL
  7 суток его чистит сам ночной батч, с P11.2; вручную: `uzel.cmd purge`).
- Какие термины модель переврала — кандидаты в словарь.
